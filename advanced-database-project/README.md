# Advanced Database Systems Project

This folder is a separate project for PfC5108-B - Advanced Database Systems.
It is intentionally independent from the LeaveSync application and database.

## Planned Contents

- `database/` - schema, seed data, views, procedures, triggers, indexes, and query scripts
- `docs/` - project documentation, normalization notes, CRUD explanations, and summary
- `diagrams/` - ERD and relationship diagrams
- `evidence/` - screenshots and demonstration results

## Assignment Coverage

The project documentation will cover:

1. System overview and target users
2. Database purpose and DBMS
3. Complete table list and table structures
4. ERD with primary keys, foreign keys, and cardinality
5. First, second, and third normal forms
6. SQL implementation and constraints
7. INSERT, SELECT, UPDATE, DELETE, and meaningful queries
8. At least one advanced database feature
9. Application/database integration
10. Screenshots, summary, and submission checklist

## Boundary with LeaveSync

This project may reuse general implementation knowledge from LeaveSync, but it will have its own schema, scripts, documentation, and evidence. No LeaveSync tables should be modified for this assignment.
